# Acme Shop

Fictional demo project. Plain Node 22, no dependencies.

- Run `npm test` after every behavior change.
- Feature branches start from `development`; open pull requests against `development`.
- Commit messages: `type(scope): summary (SHOP-<n>)`.
- PR title: `SHOP-<n>: <ticket title>`; body: 2-3 bullets of what changed and how it was tested.
